# Blackline Autopro

Привет, ты-веб разработчик сайтов с 20 летнм опытом, ты должен создать сайт с названием 
«BLACKLINE».

Технологии:

React + TypeScript.

Tailwind CSS для стилизации.

Lucide Icons для иконок.

Используй компоненты, чтобы код было легко изменять.

Сайт должен быть быстрым и корректно работать на телефонах, планшетах и компьютерах.

Дизайн:

Тёмная премиальная тема: чёрный, графитовый и белый цвета.

Яркий лаймовый цвет для кнопок и акцентов.

Крупная современная типографика.

Красивые фотографии автомобилей и процесса мойки.

Плавные анимации при прокрутке, аккуратные эффекты при наведении.

Не перегружай страницу элементами. Дизайн должен выглядеть профессионально.

Структура сайта:

Шапка: логотип BLACKLINE, ссылки «Услуги», «Цены», «О нас», «Контакты», кнопка «Записаться».

Главный экран: крупный заголовок «Чистота, которую видно», короткое описание и кнопка «Выбрать услугу». На фоне — качественная фотография блестящего автомобиля.

Услуги: карточки «Комплексная мойка», «Детейлинг», «Химчистка салона», «Полировка кузова». У каждой карточки должна быть фотография, краткое описание и примерная цена в рублях.

Преимущества: качественные материалы, внимательный подход, профессиональное оборудование.

Галерея: красивые фотографии автомобилей до и после ухода.

Цены: аккуратный прайс с несколькими вариантами услуг.

Контакты: адрес-заглушка, часы работы, телефон-заглушка и кнопка связи.

Подвал сайта с контактами и навигацией.

Функциональность:

Все кнопки и ссылки должны работать.

Кнопки записи должны вести к контактам или открывать понятную форму записи.

Добавь форму с именем, телефоном и выбором услуги.

Добавь мобильное меню.

Покажи понятное сообщение после отправки формы. Если реального сервера нет, не делай вид, что запись действительно отправлена владельцу.

Важно:

Весь текст сайта должен быть на русском языке.

Не используй Lorem Ipsum.

Не выдумывай реальные адреса, отзывы и контакты: используй явно обозначенные демонстрационные данные.

Создай законченный сайт, а не просто картинку или макет.

Сначала собери главную страницу целиком, затем проверь адаптивность и исправь обнаруженные ошибки.
